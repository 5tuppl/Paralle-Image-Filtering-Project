# Demonstration images

Generate a complete demo from the repository root:

```sh
make demo
```

This builds the programs if needed and creates deterministic examples under `data/demo/`:

- `input.png`: a 670×591 synthetic image generated by the project.
- `blur.png`: edge-clamped 3×3 blur, 10 successive passes.
- `pixel.png`: block size 8, at most 32 palette colors, ordered dithering.

Both filters preserve the input dimensions and verify their output against serial execution.
These generated files are ignored by Git. No downloaded artwork or local reference checkout
is needed. Repeating the command overwrites only these generated demo files.

The optional PNGs alongside this README are local course-presentation examples based on the
original Pixelz reference artwork. They are excluded from Git and are not dependencies of the
build, tests, or reproducible demo. The project does not claim authorship of that artwork.
